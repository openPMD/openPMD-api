Detailed Description

Container for N-dimensional, homogeneous Records.

See also
https://github.com/openPMD/openPMD-standard/blob/latest/STANDARD.md#mesh-based-records

◆ gridUnitDimension()

unit_representations::AsArrays openPMD::Mesh::gridUnitDimension ( ) const

Return the physical dimensions of the mesh axes.

If the attribute is not defined, the axes are assumed to be spatial and the return value will be according to this assumption. If the attribute is defined, the dimensionality of the return value is not checked against the dimensionality of the mesh.

Returns
